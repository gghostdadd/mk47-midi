Recording a loop

  • SHIFT + REC/OV arms the looper. Recording starts on your first note.
  • SHIFT + REC/OV again closes the loop and it starts playing.
  • While it plays, SHIFT + REC/OV punches overdub in and out. UNDO removes the most recent overdub (repeat for earlier ones).
  • With a loop stopped, SHIFT + REC/OV starts it with overdub on.

Lighting keys from MIDI

A note-on sent to the keyboard lights every key currently playing that note. The velocity picks the colour from the Launchpad 128-colour palette; velocity 0 turns it off, and note-offs are ignored. Colours are kept per MIDI channel and shown for the channel the keyboard is sending on. Try it with the light test.

SHIFT + LEDOFF clears every colour set over MIDI, on all channels, if Resolume leaves lights behind.

Good to know

  • The wide key is Enter when the keyboard is plugged in. SHIFT + ENT/SP switches it to Space. On the bass layout it plays A1.
  • Note names are QMK's: C1 is MIDI note 60 (middle C) at the default octave, lower than the usual naming. SHIFT + KOCT-/+ moves the whole keyboard by octaves.
  • Bootloader mode for flashing: hold the top-left key while plugging the keyboard in. Then use the flasher.
