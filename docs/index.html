MK47 Light Test

Sends colours to the MK47 over MIDI, the same way Resolume does. Use it on any computer to check that MIDI from the computer reaches the keyboard and lights it up. Works in Chrome or Edge.

If the keys don't light

    
    
      
  1. Use Chrome or Edge, and click Allow when the browser asks about MIDI devices. Safari has no MIDI support.
    2. 
      
  2. Close Resolume and anything else using MIDI first. Windows lets only one program use a MIDI port at a time; if the MK47 is listed but can't be opened, another program has it.
    3. 
      
  3. Round-trip check: with "Light keys I press" on, press a key on the MK47. If "Last key pressed" updates but nothing lights, the computer hears the keyboard but the keyboard isn't receiving. If "Last key pressed" doesn't update either, the browser isn't connected to the keyboard at all.
    4. 
      
  4. Several MK47s plugged in show up as "MK47", "2- MK47" and so on. Pick the one you're testing, or press a key on it to see which input it is.
    5. 
      
  5. Channel: the keyboard only shows colours sent on the channel it is playing on. Leave Channel on "All 16 channels" to rule this out.
    6. 
      
  6. Brightness: make sure the keyboard's brightness isn't turned all the way down (shift + BRI+).
    7. 
      
  7. Old firmware: builds before the MIDI-input fix ignore all incoming MIDI. Flash the latest release if nothing ever lights.
    8. 
      
  8. Works here but not in Resolume: in Resolume's Preferences → MIDI, turn on Output for the MK47, and check that feedback goes out on the channel the keyboard is set to.
