MK47 Firmware Flasher

Installs the MK47 MIDI firmware from your browser. Works in Chrome or Edge on Windows, Mac and Linux. Your brightness and other saved settings are kept.

1 Put the keyboard in bootloader mode

  1. Unplug the MK47.
  2. Hold down the top-left key (highlighted below).
  3. Keep holding it while you plug the keyboard back in, then let go.

In bootloader mode the lights stay off and the keys do nothing. That's expected. If the lights come on, unplug and try again.

2 Connect

Click Connect and choose WB Device in DFU Mode from the list the browser shows.

3 Choose the firmware

4 Flash

Connect the keyboard and choose firmware to start.

  


  

    
Troubleshooting

    

      Windows: the list is empty, or connecting fails
      
Windows needs the WinUSB driver for the keyboard's bootloader before a browser can use it. You only do this once per computer. If this PC has flashed an MK47 with QMK Toolbox before, it already has it.

      
    
        
  1. Put the keyboard in bootloader mode (step 1).
    2. 
        
  2. Download Zadig and run it.
    3. 
        
  3. In Zadig choose Options → List All Devices, then pick WB Device in DFU Mode.
    4. 
        
  4. Make sure the driver on the right says WinUSB, then click Install Driver (or Replace Driver).
    5. 
        
  5. Come back here, reload the page and click Connect.
    6. 
      

    

    

      "Unable to claim interface"
      
Another tab or program has hold of the keyboard's bootloader. Close every other tab with this page, quit QMK Toolbox or any other flasher, unplug the keyboard, put it back in bootloader mode and click Connect again. On Windows, also check the driver (above).

    

    

      The browser's list doesn't show the keyboard
      
    
        
  • The keyboard isn't in bootloader mode. If its lights are on, it started normally: unplug it and hold the top-left key while plugging it in.
    • 
        
  • Try a different USB port or cable, plugged straight into the computer rather than a hub.
    • 
        
  • On Windows, install the driver (above).
    • 
        
  • On Linux, allow access with a udev rule: SUBSYSTEMS=="usb", ATTRS{idVendor}=="342d", ATTRS{idProduct}=="dfa0", TAG+="uaccess"
    • 
      

    

    

      Flashing stopped partway
      
Don't unplug the keyboard. Click Flash again: the page writes and checks every page from the start, so a second run fixes an incomplete one. If the page lost the keyboard, reload, click Connect, and flash again.

      
If the keyboard was unplugged in the middle, it may no longer start, and holding the top-left key may no longer reach bootloader mode, because that key check is part of the firmware. Plug it in once while holding the key to check. If that doesn't work, it needs the chip's BOOT pin on the circuit board to recover.

    

    

      After flashing
      
The keyboard restarts on its own and shows up as a MIDI keyboard again. Use the light test to check the lighting.
